Install Script

Install as a native Gemini CLI extension:

gemini extensions install https://github.com/mpagot/os-autoinst-distri-opensuse-skills

Update:

gemini extensions update osado-ai-assistant
# or update all extensions:
gemini-cli extensions update --all

Uninstall:

gemini extensions uninstall osado-ai-assistant

Subscribe to the marketplace (one-time):

claude plugin marketplace add mpagot/os-autoinst-distri-opensuse-skills

Then in a Claude Code session:

/plugin install osado-ai-assistant@openqa-tools

Update:

claude plugins update osado-ai-assistant@openqa-tools

For full OSADO guidelines in every interaction, add to your project's CLAUDE.md:

@OSADO_AGENTS.md

Install as a native Antigravity CLI plugin:

agy plugin install https://github.com/mpagot/os-autoinst-distri-opensuse-skills.git

Verify:

agy plugin list

Update:

agy plugin uninstall osado-ai-assistant
agy plugin install https://github.com/mpagot/os-autoinst-distri-opensuse-skills.git

Uninstall:

agy plugin uninstall osado-ai-assistant

OCX Registry (Global)

Initialize global config (one-time), add the registry, and install skills:

ocx init -g
ocx registry add https://mpagot.github.io/os-autoinst-distri-opensuse-skills/ocx --name osado -g
ocx add -g osado/local-lint-test

Update:

ocx update -g osado/local-lint-test
# or update all components:
ocx update -g --all

Universal Skills CLI (skills.sh)

Install skills directly into supported AI coding assistants (Claude Code, Cursor, OpenCode, Codex, etc.):

List available skills:

npx skills add mpagot/os-autoinst-distri-opensuse-skills --list

Install globally:

npx skills add mpagot/os-autoinst-distri-opensuse-skills -g

Install a specific skill:

npx skills add mpagot/os-autoinst-distri-opensuse-skills --skill local-lint-test -g

Update skills:

npx skills update -g

Global Install Script (all harnesses)

Clone the repository and install skills for any supported tool:

git clone https://github.com/mpagot/os-autoinst-distri-opensuse-skills
cd os-autoinst-distri-opensuse-skills
./tools/install.sh antigravity install   # Antigravity CLI
./tools/install.sh opencode install      # OpenCode
./tools/install.sh gemini install /path/to/osado-repo
./tools/install.sh claude install /path/to/osado-repo

Update / Uninstall (replace install with update or uninstall):

./tools/install.sh antigravity update
./tools/install.sh opencode uninstall

Skills

vr-planner

Plans verification runs: unit tests, affected modules, YAML schedules, and openqa-clone-job commands.

openqa-log-analyzer

Triage openQA failures, measure command timing, detect infrastructure lag, compare runs.

openqa-log-fetcher

Fetch, cache, and inspect logs, test artifacts, and job metadata from openQA instances.

local-lint-test

Recommends the fastest local commands to validate edited OSADO code before pushing.

test-catalog

Add or audit Perldoc documentation headers following the test catalog standard.

unit-test-wizard

Writes and reviews OSADO Perl unit tests for library modules in lib/.

git-commit

Writes OSADO-compliant git commit messages for staged changes.

github-pr-create

Creates a GitHub pull request handling commit, push, and PR creation in one step.
